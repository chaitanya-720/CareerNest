# CareerNest – Your Career Starts Here 🎓

CareerNest is an Android app that helps students discover career paths and follow step-by-step roadmaps to reach their goals.

## ✨ Features
- Browse career options by field [e.g. Engineering, IT, Design]
- Step-by-step learning roadmaps for each career
-  search careers
-  save favourite careers
- Simple, clean and beginner-friendly UI

## 🛠️ Tech Stack
- Java
- Android Studio
- Gradle (Kotlin DSL)
- SQLite

## 🚀 How to Run
1. Clone the repo: `git clone https://github.com/chaitanya-720/CareerNest.git`
2. Open the project in Android Studio
3. Let Gradle sync, then run it on an emulator or Android device
